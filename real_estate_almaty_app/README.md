# 🏠 Анализ рынка недвижимости Алматы

Интерактивное десктопное приложение для анализа цен на недвижимость в Алматы на основе реальных данных (~9358 объектов).

---

## 🚀 Запуск приложения

### 1. Откройте папку проекта в VS Code

```
File → Open Folder → real_estate_almaty_app/
```

### 2. Создайте виртуальное окружение

```bash
python -m venv .venv
```

### 3. Активируйте окружение

**Windows:**
```bash
.venv\Scripts\activate
```

**macOS / Linux:**
```bash
source .venv/bin/activate
```

### 4. Установите зависимости

```bash
pip install -r requirements.txt
```

### 5. Убедитесь, что CSV-файл находится в нужной папке

```
data/cleaned_almaty_only.csv
```

### 6. Запустите приложение

```bash
python main.py
```

## 🗺️ Интерактивная карта

- Все объекты недвижимости отображаются на карте Алматы
- Используется **Canvas Renderer** (Leaflet) для плавной работы с 9000+ объектов
- Клик по объекту открывает подробную карточку справа
- Поддерживаются: масштабирование, панорамирование, подсказки при наведении

---

## 🎨 Цветовая схема (цена за м²)

| Цвет | Диапазон |
|------|----------|
| 🔴 Красный | ≥ 1 000 000 ₸/м² |
| 🟠 Оранжевый | 700 000 – 1 000 000 ₸/м² |
| 🟡 Жёлтый | 500 000 – 700 000 ₸/м² |
| 🟢 Зелёный | 300 000 – 500 000 ₸/м² |
| 🔵 Синий | < 300 000 ₸/м² |
| ⚫ Серый | Нет данных |

## 🔍 Фильтры

В верхней части интерфейса доступны фильтры:
- По цене (в миллионах ₸)
- По количеству комнат
- По году постройки
- По площади (м²)
- Флажок «Только дорогие» — показывает только красные объекты
- Флажок «Тепловая карта» — отображает тепловую карту цен
- Флажок «Кластеры» — группирует близкие объекты в кластеры
- Флажок «Вне Алматы» — показывает объекты с подозрительными координатами

---

## 📊 Статистика

Вкладка **«Статистика»** отображает:
- Средняя и медианная цена за м² по всему датасету
- Количество объектов по цветовым категориям
- Средняя цена за м² по каждому из 8 районов Алматы
- Для выбранного объекта: перцентиль цены и сравнение с районом

---

## 🤖 ИИ-ассистент

Вкладка **«ИИ-ассистент»** позволяет задать вопросы об объекте:

- _«Почему здесь такая цена?»_
- _«Дорого это или дёшево для района?»_
- _«Что рядом влияет на цену?»_
- _«Подходит ли эта квартира для жизни?»_
- _«Сравни со средней ценой района»_

**Как работает ассистент:**

1. **Без API-ключа** (по умолчанию): использует правила и шаблоны на основе данных — районная статистика, инфраструктура, год постройки, тип ремонта.

2. **С API-ключом Anthropic**: создайте файл `.env` в корне проекта:
   ```
   ANTHROPIC_API_KEY=ваш_ключ_здесь
   ```
   При наличии ключа ответы генерирует Claude AI.

Ассистент всегда отвечает **только на русском языке**.

## 📍 Адрес и объекты рядом

- **Адрес** определяется через Nominatim (OpenStreetMap) — требует интернета.
- **Объекты рядом** (школы, магазины, парки, остановки и т.д.) ищутся через Overpass API — требует интернета.
- Все результаты кэшируются в папке `cache/`, поэтому повторные запросы не требуют подключения.
- Без интернета приложение работает корректно, но адрес и объекты рядом не определяются.

## 🏙️ Определение района

Для каждого объекта определяется один из 8 административных районов Алматы:
- Алмалинский, Бостандыкский, Медеуский, Ауэзовский
- Алатауский, Жетысуский, Турксибский, Наурызбайский

**Метод:**
- Если в папке `geo/` есть файл `optional_almaty_districts.geojson` — используются точные полигоны.
- Если файла нет — используются приближённые прямоугольные границы (с пометкой «приближённо»).

Для получения точного GeoJSON скачайте данные из OpenStreetMap или ГИС-ресурсов и сохраните как:
```
geo/optional_almaty_districts.geojson
```

## 🐛 Возможные проблемы

**Приложение не запускается:**
- Убедитесь, что виртуальное окружение активировано
- Проверьте версию Python: `python --version` (нужен 3.11+)

**Карта не отображается:**
- Попробуйте запустить с флагом: `QTWEBENGINE_CHROMIUM_FLAGS="--no-sandbox" python main.py`
- Обновите драйверы видеокарты

**Файл не найден:**
- Проверьте путь: `data/cleaned_almaty_only.csv`
